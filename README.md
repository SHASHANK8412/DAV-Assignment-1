# DAV-Assignment-1
This was taken from kaggle
Dataset: combined_ipl_stats
The combined_ipl_stats.csv file is a merged dataset that brings together batting and bowling statistics of players across all seasons of the Indian Premier League (IPL). This consolidated dataset is ideal for cricket fans, analysts, and data scientists interested in player trends, performance evaluation, or predictive modeling.

Each row represents an individual player, containing both batting and bowling metrics, which allows for:

One-stop analysis of all-rounders (e.g., Hardik Pandya, Ravindra Jadeja)

Comparing pure batsmen vs. bowlers

Creating custom performance indexes (Batting SR + Bowling Econ, etc.)
